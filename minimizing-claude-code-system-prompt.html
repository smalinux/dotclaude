Minimizing Claude Code's System Prompt & Injected Context

What you can and cannot turn off through settings.json, plus the CLI-only ways to actually replace the system prompt.

Last updated: 2026-07-18

Read this first. settings.json cannot disable the main system prompt. The large block of instructions Claude Code sends is fixed and not removable through settings. What settings.json can do is trim injected context and turn off nonessential traffic and features.

To actually shrink or replace the system prompt text itself, you need CLI flags or an output style — not settings.json.

1. The only real ways to reduce the system prompt itself

These are CLI-only. They do not go in settings.json:

# Replace the default system prompt entirely
claude --system-prompt "You are a terse coding assistant."

# Add to the default without removing anything
claude --append-system-prompt "Be concise."

Or persist your own prompt via an output style. Create ~/.claude/output-styles/mine.md, then point settings.json at it with "outputStyle": "mine". An output style is the one supported persistent way to strip Claude Code's coding instructions and swap in your own.

2. settings.json — reduces traffic and context, not the prompt

This snippet is safe to paste. Every key/value below is one I'm confident is real:

{
  "env": {
    "CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC": "1",
    "DISABLE_NON_ESSENTIAL_MODEL_CALLS": "1",
    "DISABLE_TELEMETRY": "1",
    "DISABLE_ERROR_REPORTING": "1",
    "DISABLE_BUG_COMMAND": "1",
    "DISABLE_AUTOUPDATER": "1"
  },
  "includeCoAuthoredBy": false,
  "cleanupPeriodDays": 1,
  "disableAllHooks": true,
  "outputStyle": "Default"
}

What each confident option does

KeyEffect
CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFICUmbrella toggle: disables telemetry, error reporting, the autoupdater, and the /bug command together.
DISABLE_NON_ESSENTIAL_MODEL_CALLSSkips background model calls used for flavor/non-critical features.
DISABLE_TELEMETRYDisables usage telemetry.
DISABLE_ERROR_REPORTINGDisables error reporting.
DISABLE_BUG_COMMANDDisables the /bug command.
DISABLE_AUTOUPDATERDisables automatic updates.
includeCoAuthoredByfalse removes the Claude co-author line from git commits.
cleanupPeriodDaysAggressively cleans old session files (minimum 1).
disableAllHooksDisables custom hooks and status lines (less injected hook content).
outputStyleSelects the active output style; this is where you'd reference a custom prompt style.

Note: CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC already covers telemetry, error reporting, the autoupdater, and /bug, so the granular vars beneath it are somewhat redundant — kept here for explicitness.

4. Recommendation

If your real goal is fewer tokens / a leaner prompt, the highest-impact moves are:

  • Use CLI --system-prompt (or a custom output style) to replace the prompt.
  • Set CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC=1 in settings.json.

Everything else is marginal.

Caveats

  • You cannot put --system-prompt or --append-system-prompt into settings.json; they are CLI-only. outputStyle is the only persistent prompt-modification setting.
  • disableAllHooks disables your hooks and status line, but built-in tool-call handling is still enforced internally.
  • Output styles modify the system prompt (add/replace instructions); they do not strip it to nothing. Only a custom --system-prompt string fully replaces it.
  • CLAUDE.md is not a system-prompt modification — it is injected as project context, separate from the system prompt.
